Mở Swagger

Trong Swagger, bấm Authorize và dán token. Token hiệu lực 30 phút; đăng xuất hoặc đổi mật khẩu thu hồi token cũ.

Cách dùng

Mở nút “Bật API Mỹ Thuật” trên Desktop mỗi lần cần sử dụng. Bạn không cần mở Visual Studio hoặc cửa sổ SQL Server.

Đây là trang bật và thử API. Giao diện WinForms quản lý và website đăng ký là các ứng dụng riêng.
